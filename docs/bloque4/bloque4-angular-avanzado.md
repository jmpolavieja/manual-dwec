### 🚀 Bloque 4: Angular Avanzado, APIs REST y UI Profesional

::: info Visión General del Trimestre
En el **Bloque 3** aprendiste los cimientos de Angular Standalone: cómo encapsular lógica en componentes, gestionar eventos con Data Binding y organizar el estado local mediante servicios en memoria.

El **Bloque 4** (correspondiente al segundo trimestre del curso) da el salto definitivo al **desarrollo profesional de Single Page Applications (SPA)**. Transformaremos nuestras aplicaciones en sistemas completos capaces de navegar entre vistas sin recarga, conectarse a servidores remotos mediante llamadas HTTP asíncronas, validar formularios complejos y utilizar componentes UI de diseño industrial con **Angular Material** y reactividad de última generación con **Signals**.
:::
